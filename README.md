# Aether

Paint with light. A full-screen particle field — drag to stir, seven winds, Form and Nerve as glimpses in the pool.

Live: https://leaf-storm-jolly-frost.grok.me

## Run

```bash
npm install
npm run dev
```

Enter field, then Field for palettes, sound, density.

## Winds

1 Drift · 2 Orbit · 3 Weave · 4 Ember · 5 Tide · 6 Form · 7 Nerve

**S** snapshot · **G** gallery · **H** hide chrome · **M** mute

Sound: Aether (the ethereal bed), Field (live winds), or a file you choose. Volume and loop live in Field.
